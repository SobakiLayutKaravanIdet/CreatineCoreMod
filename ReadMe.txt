Hi everyone!

We are happy to present you the CreatineCore - Modding Extension (previously known as V2DLL/Unofficial Patch v3.05) - DLL-mod created by balticšprott that brings a lot more modding options and fixes to vanilla Victoria II. CC features a lot of new tweaks and script extensions, as well as previously existing modifications, known as .exe-patches. Along with modding tools, CC has a lot of performance and stability patches - most importantly, fixed multiplayer FPS and improved game speed.

CreatineCore Mod Version is just a base CC Extension packaged into the familiar mod format for Victoria 2 players and modders. It contains the files required to render features from the new patches, allowing players to see the difference for themselves and use existing developments to build their own mods or rethink the vanilla experience.

Even if you are not a modder and just play Victoria II - there is no downside in using CreatineCore (don't forget to configure it!) Almost all of the patches were tested in MP.

Main features:

-More incredible modding tools: New scriptable effects for handling population, construction, and the economy.

-Ability to create your own submods based on the CreatineCore Modding Extension without integrating them into the main version

-Customizable fixes: Tweaks for trade, factories, warfare, UI, and AI behavior. Most features can be toggled on or off individually.

-Performance: Optimizations for calculations, events, and POP processing—some of which are particularly useful for large-scale mods.

-Stability & Multiplayer: Fixes for specific crashes and desync issues, along with extra diagnostic tools to troubleshoot bugs.

-UI improvements: Additional options for data display, filters, and music control.

All of this is fully configurable via creatinecore_settings.ini file. Every patch is optional and can be disabled by changing 1 to 0 (keep in mind that some patches work in pairs!).

(Graphical elements require manual removal, but if you're already into modding, this shouldn't be an issue for you.)

You definitely need to see full list of patches for the latest mod release in PatchesList.txt

CreatineCore Modding Extension does not overwrite original game files. This ensures a safe and easy installation, allowing you to place it either in the Victoria 2 main directory or load it as a standard mod. Because of this, the mod comes in two versions - Main and Standalone:

Main Version: Integrates the extension directly into the main Vic2 directory. Extract the CreatineCore Mod Main folder from archive into the Victoria 2 root folder and overwrite any files if asked.

Standalone Version: Runs through the standard launcher like a regular mod. This is the recommended option if you want to use CC as a base for your own modding project. Just unzip files from CreatineCore Mod Standalone folder in your main game folder and it will add CC Mod as another mod in your list.

(Note: Both versions modify vanilla behavior. To get back to standard vanilla gameplay, toggle all .ini settings to 0.)
